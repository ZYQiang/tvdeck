# tvdeck

通用 ADB 设备管理 Web 工作台。把局域网里的 Android 设备——电视、盒子、投影仪、手机——接进一个网页。

- **零第三方依赖**：后端只用 Node.js 标准库，前端原生 HTML/CSS/JS，无需 `npm install`
- **厂商无关、不假设 root**：只走 AOSP 公开接口；能力先探测再执行，写操作回读验证，破坏性动作先存快照
- **单命令启动**：`npm start`，浏览器打开即用

## 功能

- **设备连接** — 局域网扫描（5555 端口）、adb mDNS 发现（Android 11+ 无线调试）、手动 IP 直连、一键重连；首次连接自动探测生成设备档案
- **实时屏幕** — 设备屏幕直播（约 5 fps，多观看端共用一路抓屏）、截图下载、全屏、纯画面页；另有「服务端画面」把主机屏幕推给其他浏览器（macOS `screencapture`，Windows/Linux ffmpeg）
- **遥控输入** — 方向 / OK / 返回 / 主页等语义按键（自适应各品牌 keylayout 扫描码）、长按、鼠标触控（点按 / 滑动）、文字输入
- **应用与文件** — 全量应用清单（含预装）+ 图标 + 名称解析；启动 / 强停 / 卸载 / 清数据 / 装 APK；设备文件浏览（系统分区只读）与主机互传
- **显示与电源** — 亮度、护眼模式、休眠 / 唤醒；设备端录屏 5–30 秒，可选 1080p / 720p
- **诊断与统计** — 系统信息、进程列表、健康快照、操作日志、屏幕使用时间与前台应用时长
- **系统配置** — 启动项、默认桌面、开机自启（先探测再执行，写后回读验证）
- **任务自动化** — 按键、启动应用、音量、护眼、电源、文字、网址、播放媒体、等待九类动作串成脚本；手动、每天定点、设备上线三种触发。只执行白名单动作，绝不执行任意 shell
- **媒体库** — 图片 / 视频 / 音频上传，设备端直接 HTTP 拉流播放（支持 Range，不转码）
- **开机自启 helper** — `tools/tvdeck-boot` 提供厂商无关的辅助 APK，开机后按配置拉起目标应用（广播 + 无障碍服务双通路）

页面自带手机窄屏适配，手机浏览器打开同一地址即可操作。

## 环境要求

- Node.js ≥ 23.6（原生跑 TypeScript，无需编译）
- adb（platform-tools）在 `PATH` 中
- 可选：ffmpeg（Windows/Linux 的服务端画面）、macOS 屏幕录制权限

## 快速开始

```bash
npm start   # http://localhost:8787，监听 0.0.0.0
```

设备侧先打开 设置 → 开发者选项 → 网络 ADB / 无线调试，然后在页面「设备连接」里扫描或输入 IP:端口。

CLI：

```bash
npm run discover [-- --full]   # 扫描局域网 ADB 设备
npm run probe [ip]             # 深度探测，生成 .tvdeck/profile.json
npm run mirror-check           # 验证服务端抓屏权限
npm run icons                  # 从设备 APK 提取应用图标
```

## 数据与配置

运行数据落在项目目录的 `.tvdeck/`（设备档案、应用名缓存、自动化脚本、媒体库、还原快照、录屏产物），环境变量 `TVDECK_HOME` 可改位置；端口用 `PORT` 覆盖，默认 8787。

## 安全须知

服务监听 `0.0.0.0`，**局域网内任何人都能访问**，请只在可信网络中运行；对外暴露请自行加反向代理与认证。文件管理对系统分区只读；改默认桌面等破坏性动作先存快照，可在页面一键还原。

## 常见问题

- **扫不到设备**：设备侧打开「网络 ADB / 无线调试」；Android 11+ 的随机端口依赖 adb 的 mDNS 报告，adb 版本需较新
- **服务端画面全黑**：macOS 在 系统设置 → 隐私与安全性 → 屏幕录制 勾选运行本服务的程序后重启；Windows/Linux 需安装 ffmpeg
- **应用没图标 / 显示包名**：运行 `npm run icons` 提取图标；名称首次访问时自动解析并缓存
